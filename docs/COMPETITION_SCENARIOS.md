# 比赛场景

所有场景均走真实政策库、确定性资格判断、材料预检与办理规划，不使用固定结果。

| 场景 | 输入与后续输入 | 预期重点 |
| --- | --- | --- |
| A 正常匹配 | “我是2025年6月毕业的本科生，在苏州创业，公司注册8个月了，想申请一次性创业补贴” | 命中一次性创业补贴，资格可继续、官方来源、材料与办理路径均展示。 |
| B 当前不符合 | “我是2020年6月毕业的本科生，在苏州创业，公司注册8个月了” | 创业补贴的毕业年限条件明确不符合，不进入申请主路径。 |
| C 多轮补充 | 首轮“我想申请创业社会保险补贴”；后续“我是2025年6月毕业的”“我交了12个月社保，继续申请创业社会保险补贴”“公司注册8个月了” | UNKNOWN 与追问逐步减少；内部画像由服务器会话保存。 |
| D 人工核验 | “我是2026届毕业生，有就业创业意愿，属于低保家庭，想申请求职创业补贴” | 历史通知或困难身份材料显示需人工核验，不显示为正式审批通过。 |
| E 材料更新 | 先运行场景 A，再点击或输入“我已经准备好营业执照或其他法定注册登记证书” | 对应材料从待确认变为已准备，资格结果不因材料状态变化而改变。 |

限制：当前仅覆盖 5 条苏州市政策；官方页面、申报窗口及最终经办审核以主管部门实际口径为准。
